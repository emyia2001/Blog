## 目录是怎么生成的

正文中的 `## 二级标题` 会自动出现在右侧目录。侧边栏还包含标签与相关文章区块。

首段会自动下沉首字（drop cap），其余段落缩进两字。这段文字就是演示。

## 可选字段速查

- `heroImage`：图 URL（可选）。封面体系已移除，不再渲染为文章头图；仅用作分享卡 `og:image` 与图谱节点图标来源，留空自动回退站点头像
- `pullQuote`：引语块，渲染在正文之前
- `bgm`：右下角迷你播放器（循环播放 + 淡入淡出 + 切页交叉淡化）；`src` 留空则不显示
- `dropCap: false`：关闭首段首字下沉（默认开启）
- `featured`：schema 预留字段，当前未消费——首页头条自动取日期最新的一篇
- `tags`：标签列表，自动生成标签页

## 内容关联（关系图谱）

关系图谱在独立的 `/graph` 页整页展示。想在某篇正文里声明与另一篇内容（文章 / 纪事人物 / 事件）的关联，用 wiki-link 语法 `[[锚点]]`：

- 锚点 = 目标节点在图谱中的**名称**：默认是它的 `title`；若目标 frontmatter 写了 `graph.name` 则优先用 `graph.name`（与标题解耦，改标题不断链）。
- 例如目标文章标题是「回来了」，正文写 `[[回来了]]`，发布后就会在 /graph 生成一条连线。

注意：

- 只有**非 draft 且 `graph.enabled !== false`** 的内容才会成为图谱节点；`[[锚点]]` 找不到目标时会静默丢弃连线（不报错），发布前建议到 /graph 复查。
- 本示例文件是 `draft: true`、不进图谱，所以上面的 `[[...]]` 只是语法示范，不会真的产生连线。
- 目前 `[[...]]` 只用于生成图谱连线，正文会原样显示方括号文字——不要拿它当正文内链（可点击的 wiki-link 尚未接入）。

## 写作建议

保持标题层级清晰（`##` 一级、`###` 二级），正文控制在 800~1500 字为宜。复制本文件为新的 `.mdx` 后，记得把 `date` 改为当天日期、`draft` 改为 `false` 或删除。

## Markdown 语法测试

下面是一组常见语法的示例，用于验证渲染效果与右侧多级目录。

### 多级标题

`##` / `###` / `####` 都会进入目录，并按层级嵌套缩进。

#### 四级标题示例

四级标题用于更细的划分，仅在目录中作为更深一级出现。

### 强调与行内样式

支持 **粗体**、*斜体*、***粗斜体***、~~删除线~~，以及行内代码 `const a = 1`。

### 列表

无序列表：

- 第一项
- 第二项
  - 嵌套子项 A
  - 嵌套子项 B
- 第三项

有序列表：

1. 第一步
2. 第二步
3. 第三步

任务列表：

- [x] 已完成的事项
- [ ] 待办的事项

### 代码块

不带语言标注：

```
vol.py -f Target.mem --profile=Win7SP0x64 pslist
```

带语言标注（显示语言标签，并支持一键复制）：

```bash
pip install pycryptodome
python2 setup.py install
vol.py -h
```

```js
function greet(name) {
  // 单行注释
  const msg = `Hello, ${name}`;
  console.log(msg);
  return msg;
}
```
